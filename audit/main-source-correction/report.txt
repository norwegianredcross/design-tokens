EXPLICIT BUILD ADJUSTMENT
The official Digdir compiler derives small/large fonts from the medium scale,
ignoring the explicit per-mode font sizes in the source sets. Its rounded spacing
can also differ across browser engines. This is why merely restoring source values
was insufficient.

After the official CLI runs, scripts/build-size-values.js reads the standard
source sets selected by $themes.json, resolves their numeric values and aliases,
and changes ONLY the values of existing numeric size and font-size declarations.
It uses Digdir's already-generated --ds-size--sm/md/lg switches. It adds no CSS
rules, selectors, layers or variables. The script contains no hardcoded design
values. It fails if the expected Digdir output structure is missing.

This is not an unmodified-CLI-output claim: it is a build-time value compilation
step that preserves Digdir's structure. A regression test compares the complete
output against official CLI output with only those size values masked. All other
CSS must be identical. Another test changes source values and verifies the rebuilt
output changes, without editing CSS. Independent builds are reproducible.
